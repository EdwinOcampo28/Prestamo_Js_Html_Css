PRESTAMO WEB
==============

INICIO EN WINDOWS
1. Extrae la carpeta PRESTAMO WEB completa.
2. Abre la carpeta.
3. Haz doble clic en index.html.

No requiere Python, SQLite, archivos BAT ni servidor.

BASE DE DATOS
La aplicación usa IndexedDB del navegador. Los datos se conservan en el mismo navegador y perfil de Windows. No se sincronizan entre equipos ni entre navegadores. No borres los datos del sitio/navegador si deseas conservarlos.

RESPALDOS
En el panel de administración, entra a Copias de seguridad y descarga un respaldo JSON periódicamente. Para recuperar, selecciona un respaldo JSON creado por PRESTAMO WEB.

MIGRACIÓN INICIAL
La primera apertura importa los usuarios, préstamos, cuotas, solicitudes y auditoría de la base SQLite incluida en el ZIP original. Las contraseñas se conservan como hashes PBKDF2; no se incluyen contraseñas en texto claro.

SEGURIDAD Y ALCANCE
Esta edición está diseñada para uso local en un solo navegador/perfil. La autenticación y los permisos se ejecutan en el propio navegador; no equivale a un servidor con sesiones HttpOnly y no debe publicarse en internet ni usarse como sistema multiusuario en red. Protege el equipo y realiza respaldos.
