# 💰 Simulador de Préstamos Financieros

Aplicación web que permite simular préstamos calculando cuotas mensuales, intereses y tabla de amortización usando la fórmula bancaria estándar.

## 📌 Características

- Cálculo de cuota mensual
- Tabla de amortización completa
- Gráfica de capital vs interés
- Diseño moderno tipo fintech
- Código modular (HTML, CSS, JavaScript)

## 🧮 Fórmula utilizada

La aplicación usa la fórmula de amortización utilizada por entidades financieras:

Cuota = P * ( r(1+r)^n ) / ( (1+r)^n - 1 )

Donde:

- **P** = monto del préstamo  
- **r** = interés mensual  
- **n** = número de cuotas
